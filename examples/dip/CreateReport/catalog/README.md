# Instrument catalog

[Instrument records](instruments.dip) are keyed collection entries. Each has
a human-readable name and a short description, so the generated section index
can list entries before their individual fields. The records use the
[instrument schema](../schemas/instrument.dipl).

These values are illustrative reference data. The guide shows their effective
values and source locations, while run adjustments belong with
[settings](../settings/README.md).
