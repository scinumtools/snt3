\subsection{Purpose}
This document describes a mock heat-flow experiment. The parameter tables show
the \textbf{evaluated} values used for one run. All values, people, and
publication references are illustrative.

\subsection{Override example}
The declared \texttt{experiment.flow\_speed} is \texttt{2 m/s} in
\texttt{parameters.dip}. The project applies \texttt{overrides.dip}, which
replaces it with \texttt{3 m/s}. Its parameter block in the Parameters section
shows the effective value, the original declaration, and the override source.

\subsection{How to read the report}
The sensor and analysis settings come from reusable schemas. The source and
custom-unit sections explain where the other inputs originated.

\subsection{Scope}
The example includes two schemas, two custom units, multiple source files,
publication details, and values with physical units. The linked contents page
leads to each main report section.
