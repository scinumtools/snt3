# README schema figure v14

- `diagram.svg` is the editable composition. It references `mountains.png` and PNG files in `icons/`.
- `diagram.png` is the self-contained README image at 1840 × 855 pixels.
- `mountains.png` was generated with the built-in image tool using this prompt: “A wide blue alpine mountain panorama, pale sky, icy peaks concentrated on the right, soft white fade toward the bottom, no text, logos, icons, or panels.”
- The C, C++, Rust, Python, and CMake logo PNGs were rendered from [Devicon](https://github.com/devicons/devicon) color logo sources. See `DEVICON-LICENSE.txt`.
- The WebAssembly logo PNG was rendered from [Simple Icons](https://github.com/simple-icons/simple-icons). See `SIMPLE-ICONS-LICENSE.md`.
- The remaining icon PNGs were rendered from [Lucide](https://github.com/lucide-icons/lucide). See `LUCIDE-LICENSE.txt`.

The SVG uses local PNG image assets; render it with a browser at 1840 × 855 pixels to regenerate `diagram.png`.
