API Reference
=============

The API reference is divided into two levels. The module APIs document the
public interfaces intended for application developers, while the
implementation APIs document the lower-level interfaces used to build,
extend, and integrate SciNumTools.

Module API
----------

The module API provides the main public interfaces of each SciNumTools
module. These interfaces are intended for users developing scientific
applications and provide access to values, expressions, physical
quantities, and dimensional input parameters.

Implementation API
------------------

The implementation API documents the lower-level C++ interfaces that form
the internal architecture of SciNumTools. These interfaces are primarily
useful when extending the framework, implementing custom solvers, adding
new functionality, or integrating directly with the underlying C++
components.
