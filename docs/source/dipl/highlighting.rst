DIPL syntax highlighting fixture
================================

This page renders the shared DIPL highlighting fixture with the local Pygments
``dipl`` lexer. It is a visual regression check for the Sphinx highlighter,
including scalar values, blocks, references, arrays, schemas, and keyed and
indexed collections.
